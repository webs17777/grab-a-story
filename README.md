# Grab a Story

A modern literary magazine celebrating storytelling, fiction, and the pleasure of a good read.

This is a simple, mobile-friendly static website. Its story collection currently displays **Coming Soon**.

## Publishing with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** from the left sidebar.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Select branch **main**, folder **/(root)**, and click **Save**.
5. Visit https://webs17777.github.io/grab-a-story/ after deployment finishes.

The site has no hosting subscription requirement on GitHub Pages for a public repository.

## Files

- `index.html`: Website content
- `style.css`: Colours, typography and responsive layout
- `script.js`: Mobile navigation and footer year

Stories can be added later without changing the site's overall design.
